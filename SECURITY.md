# Security Policy

## Supported versions

Security fixes target the latest released version of 速写. Older releases
may not receive separate patches.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, or
pull request. Use GitHub's **Report a vulnerability** form in this repository's
Security tab to submit a private security advisory.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. Do not include real user source code, credentials, or account data.

Validation and fix timelines depend on severity and reproducibility. Please
allow a reasonable remediation period before public disclosure.

## Scope

Useful reports include extension privilege escalation, unintended data
retention or transmission, unsafe page-to-extension message handling, remote
code execution, and vulnerabilities in packaged language engines. General
LeetCode platform vulnerabilities are outside this project's scope and should
be reported to LeetCode directly.
